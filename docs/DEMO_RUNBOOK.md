# Demo runbook

1. Run `npm ci`, `npm run dev`; open http://127.0.0.1:3000. The default project and six calls are synthetic.
2. Inspect the profile and normalized methods/team notes; create a project for your own facts and TXT/Markdown evidence.
3. Inspect the six match cases. Add a call using the intake form's labeled-line example. URLs are stored, not fetched.
4. Confirm modeled eligibility and the sponsor deadline from its source. Keep ambiguity unknown; exact times require the actual offset. Save to application; repeat saves reopen it.
5. Inspect quotes, confirm proposed requirements, record document progress, add missed prose requirements and confirm whole-call review. Export an agenda event; internal targets remain separate.
6. Draft/save three sections, select evidence, add exact quotes and inspect revision history. Resolve readiness blockers or record individual waivers. No-key live drafting fails recoverably. For the synthetic project, explicitly choose Demo/fixture mode, inspect and accept its preview.
7. Save edits and export Markdown. Review unresolved findings and the source appendix. Submitted records your own status only.
8. Refresh/restart and reopen saved work. Edit a source to see retained versions and stale drafts. Demo reset keeps researcher-created records.

Automated equivalent: `npm run test:browser`, after build and Playwright Chromium installation. It uses isolated data and tests the manual journey, no-key error, explicit fixtures, downloads, focus/mobile geometry, refresh and a real restart. Actual results: `implementation/STATUS.md`.
