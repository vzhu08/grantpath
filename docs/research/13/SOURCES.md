# Bootstrap source register

Researched/accessed **October 25, 2026**. Primary/official sources only. These sources support method choices and limitations; none validates the synthetic catalog, dollar/hour values, researcher availability or feasibility of a real dataset. This research performed no experiment, download of study data, package installation or benchmark.

Some NCBI/PMC and publisher full-page opens returned a browser-check or access error. Relevant official indexed content was available to web search; the methods reviewer also inspected official package manuals. An accessible search excerpt is not proof of live API/download availability. Recheck actual access and retain exact source/input versions before a future real-data workflow.
